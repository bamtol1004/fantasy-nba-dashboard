현재: API 승인 대기 수동 모드 작동

Client ID 발급 및 안전한 OAuth 백엔드 설정 후 로스터 자동 동기화 기능을 연결할 수 있습니다. 현재 파일은 Yahoo 로그인을 시도하거나 실제 로스터를 조회하지 않습니다. 승인 전에도 위 기능은 모두 수동 로스터로 사용 가능합니다.

데이터 출처 및 3개년 Blended 계산

업로드한 2024–25, 2025–26, 2026–27 선수별 시즌 누적 CSV를 경기당 평균으로 변환하여 내장했습니다. 2026–27 GP 2–4: 올해 20%, 5–9: 40%, 10–19: 60%, 20+: 80%; 남은 비중은 2025–26 70%, 2024–25 30%로 배분합니다. 2026–27 GP 0–1은 올해 기록을 제외합니다. 해당 시즌 기록이 없는 선수는 유효한 시즌으로 비중을 재배분합니다. FG%·FT%는 혼합한 경기당 성공/시도 수로 계산합니다. 임의의 예측 가중치이며 검증된 모델은 아닙니다.
